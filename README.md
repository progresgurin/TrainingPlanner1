# Training Planner / План тренировок

## Автор

Roberto Gatti

## Описание проекта

**Training Planner** — это desktop GUI-приложение для планирования тренировок. Программа позволяет добавлять тренировки, хранить их в JSON-файле, просматривать записи в таблице и фильтровать данные по дате или типу тренировки.

Проект выполнен для итоговой аттестации по техническому заданию:

- форма с полями: дата, тип тренировки, длительность;
- кнопка **«Добавить тренировку»**;
- таблица со всеми тренировками;
- фильтрация по типу тренировки;
- фильтрация по дате;
- сохранение и загрузка данных через JSON;
- проверка корректности ввода;
- Git-репозиторий;
- файл `.gitignore`;
- документация README.

## Используемые технологии

- Python 3
- Tkinter / ttk
- JSON
- unittest
- Git

В проекте не используются сторонние библиотеки. Это упрощает запуск и проверку приложения.

## Назначение файлов

- `main.py` — точка входа, запускает приложение.
- `training_planner/app.py` — графический интерфейс, кнопки, таблица, фильтры.
- `training_planner/model.py` — модель данных и проверка корректности ввода.
- `training_planner/storage.py` — сохранение и загрузка тренировок через JSON.

- `data/` — папка для пользовательского JSON-файла.
- `.gitignore` — исключает временные файлы и пользовательские данные.

## Запуск приложения

Откройте терминал в папке проекта и выполните команду:

```bash
python main.py
```

Если в системе команда `python` указывает на Python 2, используйте:

```bash
python3 main.py
```

## Как пользоваться приложением

### Добавление тренировки

1. Введите дату в формате `ДД.ММ.ГГГГ`.
2. Введите тип тренировки.
3. Введите длительность в минутах.
4. Нажмите кнопку **«Добавить тренировку»**.

Пример:

```text
Дата: 30.04.2026
Тип тренировки: Бег
Длительность: 45
```

После добавления запись появится в таблице и будет сохранена в JSON-файл.

### Фильтрация по дате

Введите дату в поле фильтра, например:

```text
30.04.2026
```

Нажмите **«Применить фильтр»**. В таблице останутся только тренировки за указанную дату.

### Фильтрация по типу тренировки

Введите часть названия тренировки, например:

```text
бег
```

Программа покажет все тренировки, где тип содержит это слово.

### Сброс фильтра

Нажмите кнопку **«Сбросить»**, чтобы снова показать все записи.

## Сохранение данных

Данные сохраняются автоматически в файл:

```text
data/trainings.json
```

Файл создаётся после добавления первой тренировки.

Пример содержимого JSON-файла:

```json
[
    {
        "id": "1777553210000000000-0",
        "date": "30.04.2026",
        "type": "Бег",
        "duration": 45
    }
]
```

## Проверка корректности ввода

В программе реализованы следующие проверки:

### Дата

Дата должна быть в формате:

```text
ДД.ММ.ГГГГ
```

Правильно:

```text
30.04.2026
01.05.2026
```

Неправильно:

```text
2026-04-30
30/04/2026
31.02.2026
```

### Длительность

Длительность должна быть положительным целым числом.

Правильно:

```text
30
45
60
```

Неправильно:

```text
0
-10
abc
```

## Тестирование

Для запуска тестов выполните:

```bash
python -m unittest
```

Тесты проверяют:

- корректную дату;
- неправильный формат даты;
- нереальную календарную дату;
- корректную длительность;
- некорректную длительность;
- добавление и фильтрацию записей;
- сохранение и загрузку JSON.
